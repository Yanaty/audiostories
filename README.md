# Тихие сказки

Одностраничный аудиоплеер на React + TypeScript + Vite. Использует react-h5-audio-player. Аудиофайлы берутся из `audio/`, сервер и база данных не нужны.

## Запуск

Требуется Node.js 22.18+ (рекомендуется Node.js 24).

```sh
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

```sh
npm test       # проверки очереди
npm run build # TypeScript и production-сборка в dist/
npm run preview # просмотр собранного сайта
```

Разместить можно на любом статическом хостинге, загрузив содержимое `dist/`. Сборка включает MP3 из `audio/`; исходные файлы остаются на месте.

## Управление

- Клик по сказке запускает её; повторный клик ставит на паузу или продолжает.
- В плеере доступны перемотка, пауза, громкость и предыдущая/следующая сказка.
- После окончания сказки автоматически запускается следующая. В конце очереди воспроизведение останавливается.
- «Перемешать и слушать» создаёт случайную очередь и начинает её воспроизведение. Список на странице остаётся по алфавиту. Клик по сказке выбирает её позицию в текущей очереди.
- «Повторять всё» зацикливает всю очередь, сохраняя её порядок.
- Таймер: выберите предустановку или введите от 1 до 1440 минут, затем нажмите «Включить таймер». Отсчёт идёт по реальному времени, в том числе на паузе. Его можно обновить или отменить. После срабатывания воспроизведение можно возобновить вручную.

Таймер работает, пока браузер исполняет страницу. При полном усыплении браузером вкладки JavaScript может приостанавливаться; при возвращении на страницу истёкший таймер проверяется повторно.

## Добавление сказок

Поместите MP3 в `audio/` и добавьте русское название в словарь `src/tracks.ts` (ключ — имя файла без `.mp3`). Перезапустите dev-сервер или пересоберите сайт. Если название не добавлено, приложение сообщит об этом. Аудиофайлы автоматически подхватываются Vite, список сортируется по русскому алфавиту.
